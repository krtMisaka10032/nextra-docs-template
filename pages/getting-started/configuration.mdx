# 配置详解

## 配置文件查找顺序

1. 环境变量 `NL2SQL_CONFIG` 指向的路径
2. 当前工作目录下的 `config.yaml`

配置中的相对路径（`audit.sqlite_path`、`glossary_file`、`fewshot_file`）**按配置文件所在目录解析**，因此从任意目录启动服务，路径行为都一致。

## 环境变量

| 环境变量 | 作用 | 优先级 |
| --- | --- | --- |
| `NL2SQL_API_KEY` | 覆盖配置中的 `api_key` | 高于配置文件 |
| `NL2SQL_CONFIG` | 指定配置文件路径 | 高于默认 `config.yaml` |

> 生产环境建议用 `NL2SQL_API_KEY` 注入密钥，避免把明文 Key 写进配置文件。

## 完整示例

```yaml
server:
  host: 127.0.0.1        # 只监听本机；对外请走 nginx 反代 / SSH 隧道并加 TLS
  port: 8731
  log_level: INFO

api_key: "changeme"      # 生产务必换成强随机值

datasources:
  - name: datav
    host: 127.0.0.1
    port: 5432
    database: datav
    user: postgres       # 本机 pg_hba 为 trust 时可省略 password
    pool: { min_size: 1, max_size: 5 }
    statement_timeout_ms: 60000
  - name: blindbox
    host: 127.0.0.1
    port: 5432
    database: blindbox
    user: postgres
    pool: { min_size: 1, max_size: 3 }
    statement_timeout_ms: 60000

defaults:
  max_rows: 100
  hard_max_rows: 1000
  timeout_seconds: 30
  max_cell_chars: 200

llm:
  cli: /root/.qoder-cn/entry/qodercn
  model: DeepSeek-Flash
  timeout_seconds: 90
  max_output_tokens: 2048
  concurrency: 3
  max_prompt_chars: 60000

nl2sql:
  max_repair_attempts: 2
  top_k_tables: 12
  fewshot_count: 3
  allow_write: false

audit:
  enabled: true
  sqlite_path: data/audit.db
  retention_days: 90

mcp:
  enabled: true
  mount_path: /mcp
  require_auth: true

glossary_file: glossary.yaml
fewshot_file: fewshots.yaml

schema_overrides:
  datav:
    tables:
      gifts:
        desc: "礼物流水底表（700万行级），分析优先用各 v_* 汇总视图"
  blindbox:
    tables: {}
```

## 配置项参考

### server

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `host` | `127.0.0.1` | 监听地址。使用 `python3 -m nl2sql_proxy.main` 启动时生效；uvicorn 命令行参数优先 |
| `port` | `8731` | 监听端口 |
| `log_level` | `INFO` | 日志级别 |

### api_key

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `api_key` | 是 | 单一管理 Key。HTTP API 与 MCP 共用；请求头 `X-API-Key` 或 `Authorization: Bearer <key>` |

### datasources

列表中的**第一个数据源**是默认数据源，也是启动时连通性校验的对象。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `name` | 必填 | 数据源标识，请求与 MCP 工具通过它路由，需唯一 |
| `host` | `127.0.0.1` | 数据库地址 |
| `port` | `5432` | 数据库端口 |
| `database` | 必填 | 数据库名 |
| `user` | `postgres` | 连接用户 |
| `password` | 空 | 密码；本机 `pg_hba` 为 trust 时可省略 |
| `pool.min_size` | `1` | 连接池最小连接数 |
| `pool.max_size` | `5` | 连接池最大连接数 |
| `statement_timeout_ms` | `60000` | 数据源级语句超时上限，请求超时不会超过该值 |

### defaults

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `max_rows` | `100` | 请求未指定 `max_rows` 时的默认行数上限 |
| `hard_max_rows` | `1000` | 硬上限。请求值、LIMIT 钳制都不会超过它 |
| `timeout_seconds` | `30` | 默认单查询超时 |
| `max_cell_chars` | `200` | markdown 单元格最大字符数，超出截断并加 `…` |

### llm

NL 模式使用的 qoder CLI 配置。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `cli` | `/root/.qoder-cn/entry/qodercn` | qoder CLI 可执行文件路径 |
| `model` | `DeepSeek-Flash` | 生成模型 |
| `timeout_seconds` | `90` | 单次 LLM 调用超时（含子进程冷启动） |
| `max_output_tokens` | `2048` | 输出 token 上限 |
| `concurrency` | `3` | 并发 qoder 子进程上限；每个子进程会占用数百 MB 内存 |
| `max_prompt_chars` | `60000` | prompt 字符上限；超过会先降级剪枝，仍超限则报错 |

### nl2sql

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `max_repair_attempts` | `2` | 生成失败后回传报错修复的最大轮数 |
| `top_k_tables` | `12` | 提示词中携带的表数量上限；表总数不超过该值时不剪枝 |
| `fewshot_count` | `3` | 每次注入的 few-shot 样例数 |
| `allow_write` | `false` | **保留字段**：当前版本的 NL 模式固定只读，该开关不会放开写权限 |

### audit

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否记录审计日志 |
| `sqlite_path` | `data/audit.db` | 审计 SQLite 文件路径（相对配置文件所在目录） |
| `retention_days` | `90` | 留存天数；每次启动时清理更早的记录，`<= 0` 表示不清理 |

### mcp

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否挂载 MCP 服务 |
| `mount_path` | `/mcp` | MCP 挂载路径（streamable-http） |
| `require_auth` | `true` | 是否校验与 HTTP API 相同的 `X-API-Key` |

### 语料与表描述

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `glossary_file` | `glossary.yaml` | 业务术语表路径 |
| `fewshot_file` | `fewshots.yaml` | few-shot 样例路径 |
| `schema_overrides` | 空 | 按数据源覆盖表/列描述，格式见下 |

`schema_overrides` 的结构：

```yaml
schema_overrides:
  <数据源名>:
    tables:
      <表名>:
        desc: "补充的表描述"
        columns:
          <列名>: "补充的列描述"
```

覆盖内容会**追加**到数据库注释之后（用 `；` 连接），不会删除原有注释。

## 修改配置之后

- 配置、`glossary.yaml`、`fewshots.yaml`、`schema_overrides` 均在**启动时加载**，修改后需要重启服务
- 仅数据库内表结构变化时，不必重启：调用 `/v1/schema?refresh=1` 强刷缓存（缓存 TTL 为 10 分钟）
- 审计库路径变更后，旧审计文件不会自动迁移
